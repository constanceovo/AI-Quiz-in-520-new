This website was created from pages 134-177 of `/Users/chensiying/Desktop/5.20复习版134-177.pdf.pdf`.

## Usage

Open `index.html` in a browser, or start a local static server in this directory:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Files

- `index.html`: page structure
- `styles.css`: minimalist visual styling
- `app.js`: quiz interaction, filtering, and progress persistence
- `data/questions.js`: multiple-choice question bank
- `data/extracted-pages-134-177.json`: raw extracted text from PDF pages 134-177
